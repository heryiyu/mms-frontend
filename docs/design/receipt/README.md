# 奉獻收據下載

權限：所有登入會員（一般會員在首頁「常見功能」只會看到這張卡片；見 [member-review/](../member-review/README.md) 的權限說明）。

收據**不是在網頁上直接下載**，而是寄到使用者填的電子信箱，附件以身分證字號當密碼（依完成頁文案推測）。

## 流程

```
會員首頁（select：點「奉獻收據下載」卡片）
  → 表單初始（default：信箱、手機空白，「確認」停用）
  → 填寫中（ing：兩欄都有值，「確認」可按）
  → 按「確認」→（推測）發簡訊 OTP 到手機
  → OTP 驗證（otp：多出驗證碼欄與「有效時間」倒數，「確認」可按）
  → 按「確認」→ 驗證成功、寄出收據
  → 完成（inf：「奉獻收據已送出，請至信箱查收！」）
  → 點「返回」→（推測）回會員首頁

任何表單狀態：web 按「取消」／mob 按「返回」→（推測）回會員首頁
```

## 需要的 API（推測，後端未定）

| 用途 | 方法 / 路徑（暫定） | Request | Response |
| --- | --- | --- | --- |
| 申請寄送收據、發送 OTP | `POST /receipts/otp` | `{ email, phone, year? }` | `{ expiresIn: 300 }`（稿中倒數 4:50，推測 5 分鐘） |
| 驗證 OTP 並寄出收據 | `POST /receipts/send` | `{ email, phone, otp, year? }` | `200`；錯誤碼：OTP 錯誤、OTP 逾時、信箱／手機與會員資料不符、該年度無奉獻紀錄 |
| 重新發送 OTP（若有） | 同 `POST /receipts/otp` | 同上 | 同上 |

後端需產生以身分證字號加密的收據檔（推測為 PDF）並寄信。所有呼叫經 `src/api/client.ts`。
