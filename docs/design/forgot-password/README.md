# 忘記密碼

> 區塊標題（`Tit.png`）：忘記密碼

## 流程

```
登入頁 default 按「忘記密碼？」（忘記密碼/default）
  → default（輸入信箱＋手機，「確認」停用）→ ing（填好，「確認」啟用）→ 按「確認」發送 OTP
  → otp（出現 OTP 欄＋倒數，輸入 OTP 後按「確認」）
  → re（設定新密碼）→ re-ing（輸入中）→ 按「確認」
  → waiting（「變更完成！」）→「返回」→ 登入頁
```

## 畫面

### 入口：登入頁（`web/忘記密碼/default.png`、`mob/忘記密碼/default.png`）
- 跟 `login/` 的 default 完全一樣，用來表示入口是卡片上的「忘記密碼？」連結（主色，在「登入」按鈕右下方）。

### default（`web/忘記密碼cot/default.png`、`mob/忘記密碼cot/default.png`）
- 版面：AuthLayout（web 右側 420px 白色卡片；mob 全寬卡片），沒有 Logo。
- 元素：
  - 標題：「忘記密碼」
  - 輸入欄：placeholder「請輸入電子信箱」
  - 輸入欄：placeholder「請輸入手機號碼」
  - 按鈕「確認」：停用（灰底膠囊）
- 互動與驗證：兩欄都填才啟用「確認」。
- web 與 mob 差異：僅版面。

### ing（輸入中）（`web/忘記密碼cot/ing.png`、`mob/忘記密碼cot/ing.png`）
- 元素：信箱「Sony88888@gmail.com」、手機「09XXXXXXXX」，「確認」變成黑底白字（主要）。
- 互動：按「確認」→ 驗證信箱與手機屬於同一個帳號，發送 OTP。

### otp（`web/忘記密碼cot/otp.png`、`mob/忘記密碼cot/otp.png`）
- 元素：
  - 信箱、手機保持已填
  - 新增一列兩欄：左為 OTP 輸入框（稿上已填「7414」）；右為灰底停用框「有效時間4：50」（倒數）
  - 按鈕「確認」：黑底（主要）
- 互動：按「確認」驗證 OTP，成功後到 re。

### re（設定新密碼）（`web/忘記密碼cot/re.png`、`mob/忘記密碼cot/re.png`）
- 版面：同一張卡片；欄位改成「左標籤＋右輸入框」，兩列之間有分隔線。
- 元素：
  - 標題：「忘記密碼」
  - 新密碼：placeholder「請輸入新密碼」，右側眼睛圖示
  - 確認密碼：placeholder「請確認新密碼」，右側眼睛圖示
  - 按鈕「確認」：黑底（稿上欄位空著時也是啟用樣式）
- 互動與驗證：兩次密碼要一致（推測），密碼規則沒畫。

### re-ing（輸入中）（`web/忘記密碼cot/re-ing.png`、`mob/忘記密碼cot/re-ing.png`）
- 元素：新密碼、確認密碼都是「XXXXXXX」，「確認」黑底。
- 互動：按「確認」送出新密碼 → waiting。

### waiting（變更完成）（`web/忘記密碼cot/waiting.png`、`mob/忘記密碼cot/waiting.png`）
- 版面：整頁 `bgLayout`，內容置中，沒有卡片。
- 元素：主色圓形勾勾圖示、標題「變更完成！」、連結「返回」（主色）。
- 互動：「返回」回登入頁。
- 備註：檔名叫 waiting，但畫面內容是「完成」，不是等待中。

## 需要的 API（推測，後端未定）
- `POST` 發送重設密碼 OTP（email＋手機，後端檢查兩者是否屬於同一帳號）
- `POST` 驗證 OTP → 回傳一次性 reset token
- `POST` 重設密碼（reset token＋新密碼）

## 待確認
- 卡片上沒有「返回」或「回登入」連結，使用者中途無法離開（註冊頁有「返回」）：要不要加？
- 沒有「已發送 OTP、但 OTP 還沒填」的狀態（註冊有）；OTP 倒數到 0 後的重新發送、過期狀態都沒畫。
- re 狀態欄位空白時「確認」已是啟用樣式，要不要改成填完才啟用？
- 錯誤狀態都沒畫：信箱與手機不符、查無帳號、OTP 錯誤、兩次密碼不一致、密碼不符規則。推測沿用登入頁的「通知」popup。
- 送出時的 loading 沒畫（推測沿用登入頁的 Logo Loading 遮罩）。
- 密碼規則（長度、英數混合等）沒寫。
- 若帳號是 Line 建立、沒有設定過密碼，能不能走這個流程？

## 用到的共用元件
- AuthLayout（web 右側 420px 卡片／mob 全寬卡片），標題置中
- 一般輸入框、密碼輸入框（眼睛圖示）
- OTP 列：OTP 輸入框＋倒數計時框（與註冊共用）
- 表單列：左標籤＋右欄位，列間分隔線（與註冊會員資料相同樣式，但這裡沒有必填星號）
- 膠囊按鈕：主要（黑底）、停用（灰）
- 結果頁：主色圓形勾勾圖示＋標題＋「返回」（與註冊「等待核准中」、登入「等待審核」共用）
