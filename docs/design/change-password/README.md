# 修改密碼

> 資料夾標題圖 `Tit.png`：「修改密碼」。本資料夾沒有設計師文字註記檔。

## 流程

```
首頁 → 點側邊選單／功能選單「修改密碼」（修改密碼/default：選單選中態）
  → 修改密碼表單（修改密碼cot/default）
  → 三個欄位都填寫（修改密碼cot/ing）→ 點「確認」(web) /「送出」(mob)
  → 變更完成（修改密碼cot/changed）→ 點「返回」→ （首頁或個人資訊，推測）

點「取消」(web) /「返回」(mob) → 離開表單（推測回上一頁／首頁，設計未標示）
```

## 畫面

### 進入修改密碼（選單選中態）（`web/修改密碼/default.png`、`mob/修改密碼/default.png`）

- 版面：與首頁完全相同（歡迎橫幅＋常見功能），差別只在 web 側邊選單「修改密碼」呈選中態（淺主色底＋主色 1px 外框）。
- 元素：同首頁（見 `../member-home/README.md`）。
- 互動與驗證：此圖用來表示「點選單修改密碼」這個動作；實作時點選後應直接顯示修改密碼表單。
- web 與 mob 差異：mob 圖與首頁完全一樣，無額外資訊。

### 修改密碼表單（預設）（`web/修改密碼cot/default.png`、`mob/修改密碼cot/default.png`）

- 版面：頁面標題＋白底圓角卡片，卡片內三列「左 label／右輸入框」，列間分隔線；底部固定操作列。
- 元素：
  - 頁面標題：「修改密碼」（粗體）
  - 欄位（皆可編輯，密碼輸入框，右側有眼睛圖示可切換顯示／隱藏，約為 Bootstrap Icons `eye-fill` / `eye-slash-fill`）：

    | Label | Placeholder |
    | --- | --- |
    | 密碼 | 請輸入密碼 |
    | 新密碼 | 請輸入新密碼 |
    | 確認密碼 | 請確認新密碼 |

  - 底部操作列：
    - web：「取消」（次要：白底黑框）、「確認」（停用：gray4 底灰字）
    - mob：「返回」（次要）、「送出」（停用），兩顆等寬
- 互動與驗證：
  - 欄位未填完時主要按鈕停用。
  - 設計未標示密碼規則與錯誤狀態；實作至少需檢查「新密碼」與「確認密碼」一致、新密碼不可與舊密碼相同（推測）。
- web 與 mob 差異：按鈕文字 web「取消／確認」、mob「返回／送出」；mob label 欄較窄、輸入框較短。

### 修改密碼表單（輸入中）（`web/修改密碼cot/ing.png`、`mob/修改密碼cot/ing.png`）

- 元素：三個欄位都已填入「XXXXXXX」（設計以明文 X 示意，實際應預設遮罩）。
- 互動與驗證：三欄皆有值後主要按鈕變為可點（web「確認」、mob「送出」，黑底白字膠囊）。點擊送出 → 變更完成。
- web 與 mob 差異：同上。

### 變更完成（`web/修改密碼cot/changed.png`、`mob/修改密碼cot/changed.png`）

- 版面：內容區正中央垂直排列；無底部操作列。
- 元素：
  - 圓圈勾勾圖示（主色線條，約為 `check-circle`）
  - 文字：「變更完成！」
  - 連結：「返回」（主色文字連結）
- 互動與驗證：點「返回」導向（未標示，推測首頁）。
- web 與 mob 差異：僅版面寬度不同。web 側邊選單「修改密碼」維持選中態。

## 需要的 API（推測，後端未定）

- `PUT /me/password`（或 `POST /auth/change-password`）：body `{ currentPassword, newPassword }`；回應需能區分「目前密碼錯誤」「新密碼不符規則」等錯誤碼。
- 若後端要求修改密碼後重新登入／作廢其他裝置 session，需回傳對應狀態讓前端處理。

## 待確認

- 第一欄 label 只寫「密碼」，應為「目前密碼」／「舊密碼」嗎？
- 密碼規則（長度、英數混合、特殊字元等）與提示文案未定義；註冊／忘記密碼流程若已有規則，是否沿用？
- 錯誤狀態沒畫：目前密碼錯誤、兩次新密碼不一致、新密碼不符規則、新舊密碼相同，錯誤訊息文案與顯示位置（欄位下方紅字？）待定。
- 修改密碼不需要 OTP（個人資訊修改需要），是否刻意如此？
- 修改成功後是否強制登出重新登入？「返回」導向哪裡？
- 「取消」/「返回」是否需要確認放棄已輸入內容？
- 麵包屑仍為「首頁」，是否應顯示「首頁 / 修改密碼」？

## 用到的共用元件

- **側邊選單（web）／mob Top Bar＋功能選單抽屜**：見 `../member-home/README.md`。
- **頂部麵包屑列（web）**。
- **表單卡片（label 左、輸入框右，列間分隔線）**：與個人資訊修改共用。
- **密碼輸入框（含眼睛切換顯示）**：可用 Ant Design `Input.Password`，圖示換成 Bootstrap Icons（`src/components/Icon.tsx`）。

- **結果頁（Result）**：勾勾圖示＋「變更完成！」＋「返回」連結；與個人資訊共用。
