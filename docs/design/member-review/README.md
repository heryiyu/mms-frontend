# 會員審核

權限：**區長以上**才看得到（首頁「常見功能」的「會員審核」卡片與本頁）；一般會員只有「奉獻收據下載」。
用途：審核新註冊的會員申請——勾選後批次「審核通過」，或逐筆「退回」。

## 流程

```
會員首頁（default：「會員審核」卡片右上紅色數字徽章 = 待審核人數）
  → 點卡片 → 待審核清單（inf：全部未勾選，「確認」停用）

【審核通過（批次）】
待審核清單 → 勾選單筆「選取」或勾「全部選取」
  → 審核（審核：至少一筆勾選，「確認」可按）
  → 按「確認」→ 只送出勾選的資料
  → 審核完成（審核完成：「審核完成！」）→ 點「返回」→（推測）回待審核清單或首頁

【退回（單筆）】
待審核清單（任一卡片）→ 點卡片底部「退回」
  → 退回確認彈窗（退回機制：「確定要退回此筆會員申請嗎？」）
     ├ 「取消」或右上 ✕ → 關閉彈窗，回清單
     └ 「確認」→ 退回完成（退回完成：「已退回！」）→ 點「返回」→（推測）回待審核清單或首頁

web 底部「取消」／mob 底部「返回」→（推測）回會員首頁
```

## 畫面

- 版面：會員首頁（詳見 [member-home/](../member-home/README.md)），主色橫幅 + 「常見功能」兩張卡片。
- 元素：
  - 麵包屑（web）：`首頁`
  - 橫幅：`Hi 彼得的魚`、`歡迎回來`
  - 區塊標題：`常見功能`
  - 卡片 1：圖示（人像 + 勾，主色淺底圓）+ `會員審核`；圖示右上角**紅色圓形徽章**，白字 `3`（colorError）。此狀態卡片為主色外框（選取／hover）
  - 卡片 2：圖示（下載）+ web `奉獻收據下載`／mob `奉獻下載`
- 互動與驗證：有未審核會員時顯示徽章與數量；點卡片 1 進入待審核清單。沒有待審核時應不顯示徽章（推測）。
- web 與 mob 差異：卡片 2 文字不同（見待確認）；其餘同。

### 審核（勾選中）（`web/會員審核/審核.png`、`mob/會員審核/審核.png`）
- 版面：同待審核清單。
- 元素：
  - 第 1 張卡片 checkbox 未勾；第 2 張卡片 checkbox 已勾（主色底白勾）
  - `全部選取` 仍未勾（只勾部分時的狀態；半選 indeterminate 樣式未畫）
  - `確認` 變為主要樣式（黑底白字膠囊）
- 互動與驗證：
  - 勾「全部選取」→ 所有卡片勾選；取消則全部取消（推測）。

  - 審核通過**沒有**確認彈窗，直接送出 → 審核完成頁。
- web 與 mob 差異：同待審核清單。

## 設計師註記

- `只送出勾選資料.png`：按「確認」時只送出有勾選的申請（批次審核通過），未勾選的不處理。
- `如果有未審核的會員需要有提示Icon.png`：首頁「會員審核」卡片要有待審核提示圖示——稿中為圖示右上紅色圓形徽章 + 數量 `3`。
- `Mob實際畫面.png`：標示 `mob/會員審核/inf-1.png` 是手機一屏的實際呈現（底部操作列固定），`inf.png` 為完整長頁展開。
- `Tit.png` 的文字是 `個人資訊修改`，與本功能不符，推測是複製區塊標題沒改。
- 全域註記：區長以上才有「會員審核」，一般會員只有「奉獻收據下載」。

## 需要的 API（推測，後端未定）

| 用途 | 方法 / 路徑（暫定） | Request | Response |
| --- | --- | --- | --- |
| 待審核數量（首頁徽章） | `GET /members/pending/count` | — | `{ count: 3 }` |
| 待審核清單 | `GET /members/pending` | （可能需 `page`、`pageSize`） | `[{ id, name, nickname, gender, email, phone, district（牧區）, group（小組）, ekk, spiritualJourney（靈程） }]` |
| 批次審核通過 | `POST /members/approve` | `{ ids: [...] }`（只含勾選的） | `{ approved: n }`；部分失敗如何回報待定 |
| 單筆退回 | `POST /members/{id}/reject` | `{ reason }`（必填，D10） | `204` |

- 權限需由後端驗證（區長以上）；前端依使用者角色決定是否顯示首頁卡片與路由。
- 清單範圍：區長是否只看到自己牧區／區的申請，由後端過濾（待確認）。
- 所有呼叫經 `src/api/client.ts`。

## 待確認

1. **退回要不要填原因？** 目前只有二次確認彈窗，無原因欄位；被退回的申請者是否會收到通知（email／簡訊）？退回後可否重新申請？
2. **退回是否支援批次？** 目前只能逐筆從卡片點「退回」；勾選狀態下點某張卡的「退回」，是否只退那一筆、其他勾選保留？
3. 審核通過是否需要確認彈窗？（目前直接送出）
4. 完成頁「返回」回到哪裡：待審核清單（顯示剩餘）還是首頁？清單全部處理完的空狀態文案未畫。
5. 「全部選取」：部分勾選時是否顯示半選（indeterminate）；是否只選目前載入／本頁的資料。
6. 清單資料量大時是否需要分頁、搜尋或篩選（依牧區／小組）？目前稿中都沒有。
7. 欄位意義與資料格式：`EKK`、`靈程`（範例 `XN`）代表什麼、是否為選項代碼；手機範例 `09XXXXXXXXX` 為 11 位，應為 10 位。
8. 審核範圍：區長只審自己區？「區長以上」的角色清單（區長、牧區長、主任牧師…）？
9. 首頁徽章數量上限顯示（如 `99+`）；數量是否即時更新。
10. web 底部 `取消` vs mob `返回` 行為與文字是否統一；清單頁底部按鈕的「取消」是否會清除勾選或離開頁面。
11. mob 退回彈窗底圖標題 `民數審核` 為誤植；`全部選取` 位置以 mob 清單稿（與標題同列）為準？
12. 首頁卡片 2 文字：web `奉獻收據下載` vs mob `奉獻下載`。
13. `Tit.png` 寫 `個人資訊修改`，是否誤植。
14. 側邊選單沒有「會員審核」項目；進入此頁時選單是否需要選中狀態、是否要在選單加入入口與徽章。
