## 6. RWD 斷點建議（Ant Design）

Ant Design 斷點：xs < 576、sm ≥ 576、md ≥ 768、lg ≥ 992、xl ≥ 1200、xxl ≥ 1600。

| 區塊 | < lg（xs / sm / md） | ≥ lg（lg / xl / xxl） |
| --- | --- | --- |
| 登入後主框架 | 手機版：top bar（Logo＋漢堡），選單收進 Drawer；不顯示麵包屑 | 桌機版：220px 固定側欄 ＋ 頂部麵包屑列 |
| 內容區內距 | 20px | 60px（目測） |

| 區塊 | < md（xs / sm） | ≥ md |
| --- | --- | --- |
| 登入頁 | 卡片寬 = 裝置寬 − 2×20px，高 fill | 卡片固定 420px 靠右，四周 40px，高 fill |
| 功能卡片 | 2 欄（手機稿即為 2 欄） | 2 欄 |

- 側欄切換建議用 **lg（992）**：220px 側欄 + 左右 60px 內距在 768 寬時只剩約 428px 內容寬，太窄；若要讓平板直向也用側欄，可改 md，需與設計確認。
- 實作：`Grid.useBreakpoint()` 判斷 `screens.lg`；側欄用 `Layout.Sider width={220}`（可設 `breakpoint="lg"` + `collapsedWidth={0}`），手機選單用 `Drawer`。
- 平板（768–991）沒有設計稿，以上為推論。
