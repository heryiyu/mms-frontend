# 會員中心首頁（登入後首頁）

> 資料夾標題圖 `Tit.png` 寫的是「創建帳號」，與本資料夾內容（登入後首頁）不符，疑似設計稿誤植，見「待確認」。

## 流程

```
登入成功 → 首頁（web/會員系統/default、mob/會員系統/default）
首頁（mob）→ 點右上漢堡圖示 → 功能選單展開（功能選單展開.png）→ 點「×」或遮罩 → 關閉選單
功能選單／側邊選單 → 個人資訊 → 個人資訊頁（見 ../profile/）
功能選單／側邊選單 → 修改密碼 → 修改密碼頁（見 ../change-password/）
功能選單／側邊選單 → 登出 → 登出（回登入頁，推測）
常見功能卡片 → 會員審核 → 會員審核頁（見 ../member-review/，推測）
常見功能卡片 → 奉獻收據下載 → 奉獻收據頁（見 ../receipt/，推測）
任一登入後頁面閒置超過 7 分鐘 → 自動登出 → 顯示「通知」彈窗（web/會員系統/自動登出、自動登出.png）→ 點「確認」或「×」→ 登入頁（推測）
```

## 畫面

### 首頁預設（`web/會員系統/default.png`、`mob/會員系統/default.png`）

- 版面：
  - web：左側固定側邊選單（白底，右側有分隔線）＋右側主內容區（頁面背景 `bgLayout`）。主內容區頂部是白底橫條，放麵包屑。
  - mob：頂部白底 top bar（左 Logo、右漢堡圖示），下方內容單欄。
- 元素：
  - Logo：「NewLife」手寫字，主色 `colorPrimary` 方形圓角底。
  - 側邊選單（web）：Logo 下方一條分隔線，選單項目「個人資訊」、「修改密碼」（此畫面無圖示、無選中態）；最底部「登出」。
  - 麵包屑（web）：「首頁」（gray2 小字）。
  - 歡迎橫幅：主色底、大圓角卡片，白字兩行：
    - 「Hi 彼得的魚」（粗體，較大字級；「彼得的魚」為會員暱稱）
    - 「歡迎回來」
  - 區塊標題：「常見功能」（粗體）。
  - 功能卡片 ×2（白底圓角卡片，內容置中，上方圓形淺主色底圖示＋下方文字）：
    - 「會員審核」—— 人像＋勾勾圖示（Bootstrap Icons 約為 `person-check-fill`）
    - 「奉獻收據下載」—— 下載圖示（約為 `download`）
- 互動與驗證：
  - 點功能卡片進入對應功能頁（設計未畫，推測）。
  - 點側邊選單項目切換頁面；選中態樣式見 profile、change-password 的 default 圖（淺主色底＋主色 1px 外框）。
- web 與 mob 差異：
  - web 有側邊選單＋麵包屑；mob 無側邊選單、無麵包屑，改為 top bar＋漢堡選單。
  - 功能卡片：web 兩張橫向等寬並排、卡片很寬；mob 也是兩欄並排（各約半寬）。
  - mob 文字字級整體較大（相對比例）。

### 功能選單展開（mob）（`功能選單展開.png`，放在資料夾根目錄）

- 版面：從右側滑出的抽屜（drawer），寬度約佔螢幕 90%，左側露出首頁並蓋灰色半透明遮罩。
- 元素：
  - 標題：「功能選單」（粗體）
  - 右上關閉按鈕「×」（約為 `x-lg`）
  - 選單項目：「個人資訊」、（分隔線）、「修改密碼」
  - 抽屜最底部：「登出」
- 互動與驗證：點「×」關閉；點遮罩是否關閉未標示（推測可關閉）。點項目後應導頁並關閉抽屜。
- web 與 mob 差異：僅 mob 有此元件；web 對應的是常駐側邊選單。

### 自動登出通知（`web/會員系統/自動登出.png`、`自動登出.png`（mob，放在資料夾根目錄））

- 版面：首頁上方蓋灰色遮罩，中央白底圓角彈窗（modal）。
- 元素：
  - 標題：「通知」（粗體置中）
  - 右上關閉「×」（灰色）
  - 內文（gray2 置中）：「因長時間未操作，系統已自動登出。請重新登入後繼續使用。」
  - 按鈕：「確認」—— 主要按鈕，**黑底（gray1）白字膠囊形**，置中
- 互動與驗證：
  - 觸發條件：超過 7 分鐘沒有任何操作（見設計師註記）。
  - 點「確認」/「×」後應導向登入頁（設計未畫，推測）。
- web 與 mob 差異：
  - mob 彈窗左右幾乎滿版（左右各約 20px 邊距）；web 彈窗寬度固定約 460px。
  - **web 此圖的側邊選單與 default 不同**：每個項目前多了圖示（三個都是同一個人像勾勾圖示），且多一個「系統設定」選單項目。mob 選單（功能選單展開.png）沒有「系統設定」。

## 設計師註記

- `超過7分鐘沒有任何行為自動登出.png` ＝「超過7分鐘沒有任何行為自動登出」：指「自動登出通知」彈窗的觸發條件，全站登入後頁面皆適用。
- `自動登出.png` ＝「自動登出」：此檔不是文字註記，而是 **mob 版自動登出通知彈窗** 的畫面稿（mob 資料夾內沒有這張）。
- `功能選單展開.png` ＝「功能選單展開」：此檔也不是文字註記，而是 **mob 版漢堡選單展開** 的畫面稿。

## 需要的 API（推測，後端未定）

- `GET /me`（或 `/members/me`）：取得目前會員基本資料，至少需要暱稱（橫幅「Hi {暱稱}」）。
- `GET /me/permissions`（或併入 `/me`）：判斷是否顯示「會員審核」「奉獻收據下載」卡片、「系統設定」選單（若為角色權限控制）。
- `POST /auth/logout`：手動登出。
- 閒置自動登出：前端計時 7 分鐘無操作 → 清除 token 並呼叫 `POST /auth/logout`。後端不需要自己的閒置逾時（2026-10-15 確認，見 `backend/README.md`「通用規則」）。

## 待確認

- `Tit.png` 文字為「創建帳號」，與首頁內容不符，是否誤植為「會員系統」或「首頁」？
- 「系統設定」選單項目只出現在 web 自動登出圖，default 與 mob 選單都沒有：是否為管理者角色才有？
- 選單項目圖示只出現在 web 自動登出圖（且三個圖示相同，像是佔位）：正式版是否要圖示？各用什麼圖示？
- 「會員審核」「奉獻收據下載」是所有會員都看得到，還是依角色（例如小組長／同工）顯示？「常見功能」數量變多時的排列（web 每列幾張、mob 是否固定兩欄）未定義。
- 自動登出：彈窗是在閒置滿 7 分鐘時立即跳出，還是使用者下次操作時才跳？是否需要登出前倒數提醒？點「確認」後導向哪裡（推測登入頁）？
- 主要按鈕在畫面中為黑底（gray1）膠囊，與 `tokens.md` 記載「主要按鈕用主色」不一致，需確認以哪個為準。
- mob 漢堡選單點遮罩是否關閉、開啟時是否鎖背景捲動，未標示。
- 麵包屑在其他頁面（個人資訊、修改密碼）也一律只寫「首頁」，疑似未更新，見各頁待確認。

## 用到的共用元件

- **側邊選單（Sidebar，web）**：Logo＋分隔線＋選單項目＋底部「登出」；選中態＝淺主色底（`colorPrimaryBg`）＋主色 1px 外框。
- **頂部麵包屑列（web）**：白底，左側麵包屑。
- **mob Top Bar**：Logo＋漢堡圖示（約為 `list`）。
- **mob 功能選單抽屜（Drawer）**：標題「功能選單」＋「×」＋選單項目＋底部「登出」。
- **歡迎橫幅（Welcome Banner）**：主色底圓角卡片。
- **功能捷徑卡片（Quick Action Card）**：圓形淺主色底圖示＋文字。
- **通知彈窗（Notice Modal）**：標題＋「×」＋內文＋單一主要按鈕「確認」；用於自動登出。
- **閒置自動登出機制（Idle Logout）**：全域計時，7 分鐘。
