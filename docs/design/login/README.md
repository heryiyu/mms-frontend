# 登入

> 區塊標題（`Tit.png`）：登入頁面

## 流程

```
default（空白）→ ing（輸入中）→ 按「登入」→ loading
  ├─ 成功 → 進入會員中心首頁（設計未畫）
  ├─ 失敗 → 通知 popup（查無此帳號／密碼輸入錯誤／登入過度頻繁 請稍後登入）→ 按「確認」或 ✕ → 回到 ing
  ├─ 帳號鎖定 → 通知 popup（登入過度頻繁 帳號以鎖定 請聯繫XXXXX）→ 回到 ing
  └─ 帳號尚未核准 → 等待審核頁 → 「返回」→ default
```

其他出口：
- 「進度查詢」→（推測）等待審核頁或審核進度查詢，設計未畫
- 「忘記密碼？」→ 忘記密碼流程（見 [../forgot-password/](../forgot-password/README.md)）
- 「使用Line快速登入」→ Line OAuth（設計未畫）
- 「註冊帳號」→ 創建帳號流程（見 [../register/](../register/README.md)）

## 設計師註記
- `前端要做阻擋.png`＝「前端要做阻擋」。註記圖只有文字、沒有箭頭；依位置推測指「登入過度頻繁」：前端要擋住連續送出（例如 loading 期間停用按鈕、達到次數後暫停送出）。也可能指欄位未填或格式錯誤時不能送出。
- `聯繫內容應該是教會Mail 然後需要確認後再發信跟User說已經解Ben.png`＝「聯繫內容應該是教會Mail／然後需要確認後再發信跟User說已經解Ben」。指「鎖住帳號」popup 與「等待審核」頁的「請聯繫XXXXX」：XXXXX 要換成教會 Email（mailto 連結）。教會確認後要寄信通知使用者帳號已解鎖（後台／後端流程）。

## 需要的 API（推測，後端未定）
- `POST` 登入（email、password）→ 要能分出：成功（token／session）、查無帳號、密碼錯誤、暫時頻率限制、帳號已鎖定、帳號待審核
- Line OAuth 登入：取得授權網址、callback 換 token
- 進度查詢：查審核狀態（輸入什麼條件查，設計未畫）
- （後台）解鎖帳號並寄信通知使用者

## 用到的共用元件
- AuthLayout：web 右側固定 420px 卡片＋左側 fill；mob 全寬卡片
- BrandHeader：Logo＋「新生命會員中心」＋英文副標
- 密碼輸入框（右側眼睛圖示切換顯示），對應 Ant Design `Input.Password`
- Checkbox（主色勾選）
- 膠囊按鈕：主要（黑底白字）、停用（gray4 底灰字）、次要外框（白底黑框，可帶圖示，例如 Line）
- 文字連結（主色）
- 「or」分隔線（`Divider`）
- 通知 Modal：標題「通知」＋✕＋內文＋「確認」膠囊按鈕
- 全頁 Loading 遮罩：Logo＋「Loading」
- 狀態結果頁：置中標題＋說明＋聯繫連結＋「返回」
