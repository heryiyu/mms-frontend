# 創建帳號（註冊）

> 區塊標題（`Tit.png`）：創建帳號

## 流程

一般創建：
```
Default（出生／信箱／手機）→ 按「確認」→ ing（送出 OTP，顯示 OTP 欄＋倒數）
  → otp（輸入 OTP，「確認」啟用）→ 個資保護聲明（合約滑到底才可勾選同意）
  → 會員資料輸入 → 會員資料輸入中（選教會後展開牧區／小組／EKK）→ 確認
  → 等待核准中（完成頁）→「返回」→ 登入頁
```

未成年分支：
```
Default 選的出生日期未滿 18 歲 → 未成年判斷/ing（出生欄下方多一個「監護人名稱」欄）→ 之後接回一般流程（推測）
```

Line 創建：
```
Default 按「使用Line創建帳號」→ Line 授權（設計未畫）→ line審核成功（「Line創建成功／自動跳轉中請稍後」）
  → 自動跳轉，接回一般創建流程（接回哪一步見待確認）
```

任何步驟輸入錯誤 → 跳 popup 提醒（依註記，樣式推測沿用登入頁的「通知」對話框）。
審核沒通過 → 用 Mail 或手機簡訊通知使用者（後端流程）。

## 設計師註記
- `合約滑到底才能勾選.png`＝「合約滑到底才能勾選」：指「個資保護聲明」頁。捲動區要捲到底，「本人同意個資保護之聲明」checkbox 才能勾（之前停用）。
- `出生未滿18歲後須做監護人資料欄位.png`＝「出生未滿18歲後須做監護人資料欄位」：指「未成年判斷」。出生日期算出未滿 18 歲時，要多一個監護人資料欄位（稿上只有「監護人名稱」）。
- `發Mail或手機通知沒有申請成功.png`＝「發Mail或手機通知沒有申請成功」：指送出後的審核結果。審核沒通過時，用 Email 或手機簡訊通知使用者（後端）。
- `輸入錯誤需跳pop提醒.png`＝「輸入錯誤需跳pop提醒」：指整個創建流程的欄位錯誤（例如 OTP 錯誤、格式錯誤、密碼不一致），要跳 popup 提醒。popup 樣式沒畫，推測沿用登入的「通知」對話框。
- `Line審核成功後接回一般創建流程.png`＝「Line審核成功後接回一般創建流程」：指「line審核成功」頁自動跳轉後，接回一般創建流程。
- 註記圖只有文字，沒有箭頭指向；上述對應是依檔名內容推測。

## 需要的 API（推測，後端未定）
- `POST` 發送手機 OTP（出生日期、email、手機；可能同時檢查 email／手機是否已註冊）
- `POST` 驗證 OTP
- `GET` 個資保護聲明內容（或寫死在前端）
- `GET` 教會列表；`GET` 牧區（依教會）；`GET` 小組（依牧區）；`GET` EKK（依？）
- `GET` 靈程選項（或固定 NF／VIP／XN）
- `POST` 送出註冊（基本資料＋會員資料＋監護人資料＋同意聲明）
- Line OAuth：取得授權網址、callback 綁定／建立帳號
- （後端）審核結果通知：Email／簡訊

## 用到的共用元件
- AuthLayout（web 右側 420px 卡片／mob 全寬卡片），標題置中，底部「返回」文字連結
- 日期輸入框（右側月曆圖示），對應 Ant Design `DatePicker`
- OTP 列：OTP 輸入框＋倒數計時框（灰底停用樣式顯示「有效時間m：ss」）
- 膠囊按鈕：主要（黑底）、停用（灰）、次要外框（白底黑框，可帶 Line 圖示）
- 「or」分隔線
- 合約捲動框＋同意 Checkbox（捲到底才啟用）
- 表單列（FormRow）：左標籤＋紅色必填星號＋右欄位，列間分隔線
- Radio 單選群組、Select 下拉（向下箭頭）、密碼輸入框（眼睛圖示）
- 底部固定操作列：「返回」外框＋「確認」主要
- 結果頁：主色圓形勾勾圖示＋標題＋說明＋聯繫連結＋「返回」
- 錯誤提醒 popup（推測沿用登入的通知 Modal）
